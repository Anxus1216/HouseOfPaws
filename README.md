# 爪爪小屋

一款轻松治愈的竖屏微信小游戏。领养奶糖、糯米、团团，在小屋里喂食、清洁、玩耍、休息，接住星星陪伴萌宠成长。

## 运行

使用微信开发者工具打开本目录，项目类型选择「小游戏」，点击编译即可体验。项目使用微信小游戏 Canvas API 和本地存储，不需要安装依赖或配置服务端。

## 玩法

- 首次进入免费领养奶糖，并通过三步可跳过引导认识小屋；通过每日礼物、任务、小游戏和升级奖励积攒爪爪币，继续领养糯米和团团。
- 每只宠物分别保存四项状态、等级与经验。在「萌宠」页切换当前陪伴的宠物。
- 每只萌宠每天最多获得 100 点成长值，照料与「星星接接乐」共用当日额度；最后一次奖励按剩余额度结算。额度用尽后仍可照料和游玩，只是不再增加成长值。小屋会显示今日已获得的成长值及照料后的实际变化。
- 「任务」页每天提供照料、互动、完成小游戏三个目标，完成后可领取奖励。
- 「星星接接乐」中左右滑动篮子接星星，每局 20 秒，奖励爪爪币、快乐值与经验；可暂停，切到后台后保持暂停。
- 状态按现实时间缓慢变化，前台、存档和返回前台使用同一结算规则；单次离线结算最多 24 小时。自然衰减以 15 为下限，照料动作已造成的更低数值不会被结算抬高。每天可领一次 30 爪爪币。
- 三只萌宠有不同的轮廓和表情，照料时显示动作反馈。设置中可关闭音效。
- 抚摸反馈持续 1.8 秒，喂食、清洁、玩耍反馈持续 2.4 秒，休息反馈持续 3 秒；表情、动作图和气泡同步结束，然后按当前饱腹、清洁、快乐、精力显示持续状态与提示。

## 代码

- `js/model.js`：养育规则、奖励、存档兼容与离线结算。
- `js/care-actions.js`：四种照料的属性变化、奖励与反馈配置；目标属性在界面显示为 100% 时不消耗资源或领取奖励，玩耍需要至少 29 点精力。
- `js/scene.js`：Canvas 场景与简约水粉主题界面绘制。启动时预载五张场景图，照料与游戏切换复用缓存；萌宠状态图按需加载。图片未就绪时显示备用底色或 Canvas 萌宠造型，加载完成后自动重绘。
- `assets/pets/sprites/`：奶糖、糯米 B、团团 C 各八种表情或照料状态，共 24 张透明 PNG；原图与打包规范见 `assets/pets/README.md`。
- `assets/scenes/`：小屋午后、清洁角、玩耍庭院、晚间休息和接星星夜空五张正式 JPEG 背景。首页随照料反馈切换背景，游戏页使用夜空图；运行时按容器比例裁切，短屏夜空取景偏上以保留月亮。可用 `scripts/package-gouache-scenes.ps1 -Source <评审原稿目录>` 从五张已确认的 PNG 原稿重新打包。
- `js/main.js`：微信生命周期、触摸输入、小游戏和存档调度；静态页面在交互或状态变化时重绘，宠物动画和进行中的小游戏逐帧绘制；小游戏按实际经过时间倒计时，掉帧时分步推进星星运动。
- `js/debug-editor.js`：开发调试模式的数据草稿、字段校验和原子保存；入口默认关闭。
- `audio/*.wav`：原创短音效；`scripts/generate-audio.mjs` 可重新生成。
- `docs/本轮开发方案.md` 和 `docs/体验与验收.md`：本轮范围、设计与回归清单。
- `docs/UIUX设计评审.md`：界面问题、纸艺手帐视觉方案与关键玩家路径。

宠物与场景采用本地厚线水粉图片，无远程资源依赖；界面使用奶油色纸面、浅木色分隔和陶土色操作按钮，由 Canvas 绘制。存档仅保存在当前设备的微信小游戏本地存储中。

## 开发调试模式

调试入口默认关闭。需要测试特殊数值时，将 `config/debug.local.example.json` 复制为 `config/debug.local.json`，确认其中 `debug.enable` 为布尔值 `true`，再执行 `npm run debug:prepare` 并在微信开发者工具中重新编译。设置中会出现「调试模式」，可编辑当前陪伴萌宠的状态、等级、经验、照料次数、今日成长，以及爪爪币和今日任务。编辑器用屏内数字键盘输入；点击字段后，首个数字会替换旧值。修改直接写入当前设备存档，调试前请使用隔离测试存档。

缺少本地配置文件、缺字段或设为 `false` 时，执行 `npm run debug:prepare` 会关闭入口。`config/` 不打包，本地配置不提交。发布前执行 `npm run release:check`，该命令生成关闭的运行时配置，检查打包忽略项并运行测试；此后重新编译发布包。切换配置不会回滚已保存的游戏数值。需求和技术设计见 `docs/开发调试模式PRD.md`、`docs/开发调试模式开发方案.md`。

## 验证

运行 `node --experimental-default-type=module --test tests/*.test.mjs` 检查养成规则与主要页面操作。存档在原有本地键下升级到版本 3，旧版数据会自动迁移。发布前仍需在微信开发者工具的至少两种真机比例上检查字体、触摸、安全区域、音效和性能；记录表见 `docs/体验与验收.md`。
