# 厚线水粉状态图生成规范

模式：内置 `image_gen`；每个状态单独生成一张，输出透明背景 PNG。以本目录对应宠物的 `pet_<id>_normal.png` 作为角色参考。始终完整保留头身比、耳朵和尾巴形状、额头/脸部花纹、配饰、深焦糖色粗水粉轮廓、哑光色块与画布留白。单只宠物居中，禁止场景、文字、边框、3D、毛绒玩具与地面阴影。

基础形象生成提示：完整全身、左向三分之四视角、轻抬一只前爪、约两头身；二维厚线水粉绘本画法、深焦糖色手绘粗轮廓、哑光不透明色块、少量局限于角色内部的干笔触，手机 96px 下依然清楚，透明背景。糯米补充燕麦奶色毛发、两侧垂耳、粉耳心、云朵额毛、薄荷围巾与棉球尾；团团补充焦糖柴犬毛色、奶油色口鼻与胸口、立耳、卷尾、棕项圈与金星吊饰。

角色识别元素：奶糖是奶油小猫，焦糖 C 形额纹、两颊各三点雀斑、珊瑚围巾和金铃铛；糯米是燕麦奶色垂耳兔，云朵额毛、粉耳心、薄荷围巾和棉球尾；团团是焦糖柴犬，奶油色口鼻与胸口、立耳、卷尾、棕项圈与金星吊饰。

| 文件后缀 | 具体变化 | 不应出现 |
| --- | --- | --- |
| normal | 清醒、亲近的待机姿态，轻抬一只前爪 | 大幅改变身份或配饰 |
| happy | 双眼弯成开心月牙、张嘴笑、前爪微抬 | 额外庆祝文字或道具 |
| sleepy | 半闭眼、轻打哈欠、耳朵与爪子放松 | 星号、字母 Z 或背景 |
| need | 委屈的下垂眉眼、轻微噘嘴，需要被照顾 | 重病、眼泪泛滥、负面恐怖元素 |
| feed | 开心进食，靠近嘴边有一小块合适的食物 | 大型餐具遮挡角色 |
| wash | 愉快洗净，身边少量浅蓝泡泡 | 泡泡遮挡脸或配饰 |
| play | 兴奋互动，与一只小珊瑚色球玩耍 | 多个玩具或场景 |
| rest | 安心蜷卧休息、双眼闭合 | 文字、床或复杂道具 |

最终素材须通过透明通道、角色一致性、全身无裁切和小尺寸可读性检查。若图像生成偶尔改变雀斑数量、额纹或配饰，应针对该图重试，不把有偏差的版本直接作为正式精灵。
