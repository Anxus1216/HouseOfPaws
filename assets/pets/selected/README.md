# 厚线水粉萌宠素材

本目录保存厚线水粉风格的 24 张正式原图，可通过打包脚本生成 `../sprites/` 运行素材。早期基础稿和造型备选属于本地设计探索稿。

造型选择已确定：奶糖采用厚线水粉原版；糯米采用 B 版（团子头、包裹式垂耳）；团团采用 C 版（活泼站姿、吐舌笑）。三只宠物的八种状态图以 `pet_<id>_<state>.png` 命名，共 24 张。可打开 [状态总览](preview.html)比较大图和游戏卡片尺寸。

三只角色设定：

| ID | 名称 | 不可变的识别元素 |
| --- | --- | --- |
| cat | 奶糖 | 奶油色毛发、焦糖额头卷纹、两颊雀斑、珊瑚围巾、金铃铛、卷尾 |
| rabbit | 糯米 | 燕麦奶色毛发、两侧垂耳、云朵额毛、粉耳心、薄荷围巾、棉球尾 |
| dog | 团团 | 焦糖柴犬、奶油色口鼻和胸口、立耳、卷尾、棕项圈和金星吊饰 |

每只角色需要八种状态，文件名为 `pet_<id>_<state>.png`：

| 状态 | 图像要求 |
| --- | --- |
| normal | 清醒、亲近、稳定的基础形象 |
| happy | 明显的快乐表情与抬爪动作 |
| sleepy | 半闭眼、困意、放松姿态 |
| need | 需要照料的委屈表情，避免呈现严重病态 |
| feed | 开心进食，食物与嘴部动作清楚 |
| wash | 被清洗，少量泡泡与清洁动作 |
| play | 活跃玩耍，与球或玩具互动 |
| rest | 安心休息，闭眼或蜷卧 |

已检查 24 张文件完整、PNG 左上角透明通道存在。运行素材已统一画布、锚点与文件体积并接入游戏；本目录保留高分辨率原图供迭代。发布前仍需在微信开发者工具和真机检查加载与画面比例。
