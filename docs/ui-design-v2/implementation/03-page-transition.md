`page-transition.js`是纯状态机：`ui.page`立即表示最新业务目标，`displayPage`表示正在绘制的内容。淡出期间换目标不重置截止，淡入中反向从当前透明度续接；不排队，重复点最新目标不重播。长帧和零时长立即收敛。

集成时：原入口先完成业务核验，离开游戏立即暂停；导航仍可切换，过渡中的内容不能照料、领奖、领养或拖动游戏。内容、导航、游戏暂停/退出前景和通用弹层分层，保留已有阻断语义；完成帧强制完整重绘后恢复命中。

后台、有效视口变化时完成到最新目标并取消旧触摸；恢复后刷新业务，不自动继续游戏。图片就绪只请求重绘，不重播过渡。减少动态采用可注入零时长策略，不虚构平台API或新增玩家设置项。
