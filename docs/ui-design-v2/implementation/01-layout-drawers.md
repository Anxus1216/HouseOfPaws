# 布局与双抽屉接入

分支：`feat/ui-v2`。对应已确认PRD的UI-01至04、07至10；本批仅实现布局和抽屉基础，完整教学、结果归并和页面过渡分别提交。

- 新增`home-layout.js`，按实际安全窗口和胶囊留白计算矩形，逆变换至Scene坐标；入口、命中和导航共用布局。

- 宠物锚点不随抽屉开合变化，动画/隐藏子项不能触发照料，面板空白不穿透抚摸。
