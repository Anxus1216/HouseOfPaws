# 爪爪币展示恢复与同轮回退验证

## 原因与修改

历史核对：`efbb835` 接入 UI-v2 时，把旧版 69×32 设计单位、半高圆角的矮胶囊改成了 64×44 窗口逻辑像素。最近四条响应式修复没有修改爪爪币样式；紧凑页和完整页还使用了不同的绘制路径，导致机型与页面间比例不一致。

恢复原矮胶囊形式，并统一采用 69×32 窗口逻辑像素、16px 圆角及 13px 文字。小屋、萌宠、任务、游戏首页、游戏运行/结果及欢迎页共用绘制路径。设置按钮保留 44px 点击区域；名称区、胶囊和设置按钮之间各保留 4px 间距；欢迎页继续遵守设置按钮的显示条件。

同轮单独反向撤销 `b09500c`，状态抽屉恢复 268px 上限及原四行排版；入口同宽、半圆进度及其他已完成修复保留。详见 [回退记录](11-status-height-revert.md)。

## 实际验证

- `npm test`：151/151 通过。新增测试覆盖 320×568、390×844、430×932，以及 1/3 倍像素密度，核对各页胶囊尺寸、圆角、文字尺寸、名称间距和设置命中；游戏运行/结果与欢迎页由自动化覆盖。
- 独立审查运行钱包、抽屉、主题、安全区及游戏冒烟测试：42/42 通过，最终差异未发现问题。
- 微信开发者工具 Stable 2.02.2608080：核对当前项目及 `feat/ui-v2` 提交历史，重新编译后实际检查 iPhone 5 320×568 与 iPhone 15 Pro Max 430×932。
- 两机型均实际点击小屋、萌宠、任务、游戏首页导航，核对爪爪币形态和留白一致；展开状态抽屉确认恢复原高度及弧线。长屏另检查设置按钮打开和关闭。
- 长屏使用 100% 核对局部比例，85% 预览核对完整画面；检查后恢复 iPhone 5、100% 预览及小屋。没有清空缓存、覆盖存档或领取奖励，爪爪币保持 60。
- 开发工具切换机型时出现过一次模拟器长时间无响应提示，关闭提示并待重新布局完成后沿相同路径检查正常。

## 限制

没有进行真机验收。六位最大金额未做实际画面核对；没有为验证欢迎页重置模拟器存档，欢迎页由自动化覆盖。模拟器检查不等同真机验收。
