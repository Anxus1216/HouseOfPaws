# 照料反馈与入口教学

分支：`feat/ui-v2`。本批承接布局功能，按已审核方案接入结果呈现和教学；不包含主页过渡。

界面反馈使用实际结算差值，费用、成长与升级返币分别表达；连续操作在同宠物的有效反馈期内汇总到单一卡片。满值与失败理由复用原文案，保存失败不重做业务结算。

宠物台词与建议动作一致时，场景辅助区显示宠物台词，点按可查看操作说明。四项属性百分比在状态抽屉查看，照料结果仍显示实际属性变化。

新存档的`guide.uiHints`是可选教学元数据，仅记录真实打开过照料/状态入口。旧存档缺失或非法字段为null，不补播新增教学；主事实、存储键及版本保持不变。菜单打开不算照料成功，查看状态不阻挡领奖，跳过结束整个主教学。

调用方加载后继续执行`reconcileGuide`再派生提示。子提示只在小屋显示；其他页面保留原主教学的导航目标。主流程成功事实和实际结果优先，提示位置由真实布局计算。

独立模块验证42/42通过，额外15组兼容边界通过；实际Main/Scene接入、短屏显示和最终回归结果见后续验收记录。
