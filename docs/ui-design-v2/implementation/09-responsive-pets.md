# 小屋与游戏首页宠物比例适配

小屋宠物边长按场景宽度 76%、高度 60% 取较小值，并受场景边缘及照料面板安全距离约束，保持场景中央，不再固定上限为 190px。图片始终按正方形等比显示，照料前景跟随同一比例。

游戏首页新增纯展示布局：宠物按场地宽度 76%、高度 55% 和气泡可用空间取较小值；篮子跟随宠物同比例调整，气泡位于图片上方。开始按钮保留原场地底部位置。游戏场地、碰撞、移动范围和结算逻辑不变；结果页标题旁的装饰宠物保留原受限尺寸。

自动化覆盖 320×568、390×844、430×932、390×1000，验证尺寸增长、居中、等比、反馈/照料/气泡/按钮边界，以及游戏物理场地不受展示布局影响。最终全量测试与模拟器结果见 [响应式适配验收记录](10-responsive-verification.md)。
