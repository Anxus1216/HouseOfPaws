# 爪爪小屋｜UI/UX 评审与视觉方案

## 设计判断

游戏的目标是让玩家在短时间内与宠物建立温柔、可持续的陪伴关系。现有版本的规则、角色素材和页面结构已覆盖领养、照料、任务、小游戏及次日回访，但界面需要更清楚地回答三个问题：**现在关注谁、接下来做什么、做完得到了什么。**

| 原界面问题 | 对体验的影响 | 本轮处理 |
| --- | --- | --- |
| 首页房间、状态和操作多为接近的浅色区域 | 角色与主要操作缺少明显的视觉主次 | 用纸艺小舞台突出宠物；状态留在舞台下方，照料动作独立成一排 |
| 首次进入同时展示三只角色，但初始金币不足以领养后两只 | 新玩家在第一步遇到无效选择 | 首次进入只突出免费领养奶糖；另外两只在领养后通过“萌宠”页认识 |
| 照料按钮未显示成本与可用状态 | 玩家需点击后才知道是否能执行 | 按钮显示“免费 / ✦ 5”，满状态、金币或精力不足时降低视觉强调，仍可点击获取原因 |
| 首页缺少通往任务奖励的近路；任务未完成时按钮只有状态说明 | 完成照料后不容易发现下一步 | 首页显示待领奖励数量；任务卡提供“去完成 / 领取奖励 / 已领取”三种状态 |
| 小游戏场景与小屋使用近似浅色，星星主题不够鲜明 | 游戏入口与 20 秒玩法缺少情绪切换 | 使用与奶油纸张搭配的深青绿夜空，金色星星成为焦点 |

## 视觉语言

主题是**午后甜点小屋里的纸艺手帐**。暖奶白是底纸，浅杏色是房间与卡片，焦糖棕承担正文，珊瑚色只强调可执行主动作；薄荷绿与金色用于成长、奖励和小游戏。线条与圆角保持柔软，但正文、按钮和进度信息拉开明度差，避免整屏“浅而糊”。

- **角色优先：**房间采用窗、阳光、墙线和地毯构成的轻舞台，沿用已选定的厚线水粉宠物素材。角色在首页始终位于中央。
- **明确动作：**主要按钮带文字，不依赖图形符号单独传意；照料四项同时出现，首次领养只有一个主按钮。
- **持续反馈：**已有表情、动作图、气泡与数值变化继续同步；低于 25 的状态在文字与进度条上转为珊瑚色。
- **可重复的日常：**任务在“去完成、待领取、已领取”之间清晰切换；首页给出待领取数量，小游戏结束继续显示奖励。

## 页面路径

1. **首次进入：**认识奶糖 → 免费领养 → 可跳过的三步引导 → 首页照料。
2. **每日照料：**查看状态 → 选择照料 → 表情、数值和成长反馈 → 首页进入待领奖励 → 领取任务奖励。
3. **拓展陪伴：**在萌宠页查看三只角色、当前陪伴者及领养差额；金币不足时提示还需多少。
4. **小游戏：**阅读 20 秒玩法提示 → 开始接星星 → 查看得分和奖励 → 再玩或回小屋。

## 适配与验收

界面保持 390 逻辑宽度，按可用安全区缩放；首页房间随屏高收缩，导航和主要操作固定在底部安全区上方。本轮通过自动测试检查 390×680 的按钮边界与首页状态区，并在微信开发者工具模拟器中查看小屋、萌宠、任务和游戏页面。发布前仍需在至少两种真实手机比例上检查文字、触摸和系统安全区。
